## 2024-11-01 - Avoid Cache Entry Mutation on Reads
**Learning:** Mutating cache entry fields (like `AccessedAt`) while holding only an `RLock` leads to data races and CPU cache invalidation, which severely degrades performance under highly concurrent workloads. The `AccessedAt` metadata wasn't being used anywhere for eviction because eviction logic is decoupled via explicit callbacks.
**Action:** In highly concurrent systems, ensure that read paths remain strictly read-only on the shared data structure and its members when using an `RLock`. If access metadata must be updated, it should be managed separately or batched lock-free unless strictly necessary.
